## 组2｜DOL Form 5500 养老金计划审计费：log(IQPA 审计费) ~ log(总资产) × 103(a)(3)(C) 有限范围审计（2026-09-30）
- 数据源：https://www.dol.gov/agencies/ebsa/about-ebsa/our-activities/public-disclosure/foia/form-5500-datasets （2024 Latest，主表 + Schedule H）
- n = 9,250 个计划（每发起人 EIN 1 行；训练 6,475）；Y = ln(IQPA 审计费，由计划资产支付部分)，X = ln(年末总资产)，G = 有限范围审计（103-8）vs 完整审计；16 个控制变量
- 关键数字（训练集，预设设定、仅 1 次）：R² = 0.298，adj R² = 0.295，ΔR² = 0.022；斜率 完整 0.173 / 有限 0.111；P10→P90 = 0.84 SD / 0.54 SD；交互 −0.062，p = 7e-8，HC3 p = 3e-6；替代交互（×集体谈判、×参与人贷款、×DB、×参与人数）全部通过
- 诊断：残差偏度 −2.29、超额峰度 19.2（部分付费造成的极小审计费）；按审计师 ICC = 0.089（红旗，>0.05）
- 失败原因：R² 0.30 远低于 0.50 门槛（Y 只记录计划资产支付的部分审计费，噪声大）；另有审计师聚类 ICC > 0.05

## 组2｜SCF 2022 家庭总资产：log(总资产) ~ log(工资收入) × 金融素养三题全对（2026-09-30）
- 数据源：https://www.federalreserve.gov/econres/scfindex.htm （SCF 2022 公开摘要数据 SCFP2022，仅第 1 个插补）
- n = 2,571 户（户主 25–64 岁、工资 > 0；训练 1,800）；Y = ln(ASSET)，X = ln(WAGEINC)，G = FINLIT = 3；控制：年龄及平方、教育、种族、婚姻、子女数、性别、职业、行业、风险态度
- 关键数字（训练集，预设设定、仅 1 次）：R² = 0.655，adj R² = 0.651，ΔR² = 0.088；斜率 非满分 0.97 / 满分 0.83；P10→P90 = 1.00 SD / 0.85 SD；交互 −0.14，p = 0.041，HC3 p = 0.12；加权 WLS 交互 p = 0.74；加 ln工资×大学、×年龄、×种族 后 HC3 p 0.11–0.16
- 失败原因：交互 p = 0.041 > 0.01 且 HC3 p = 0.12 > 0.05，方向与文献假设相反，加权后消失；残差超额峰度 4.8

## 组2｜SEC Form N-CEN 基金经纪佣金：log(年度经纪佣金) ~ log(月均净资产) × 指数基金（2026-09-30）
- 数据源：https://www.sec.gov/data-research/sec-markets-data/form-n-cen-data-sets （2025Q3–2026Q2 四个季度，每 SERIES_ID 取最新申报）
- n = 8,549 个开放式基金/ETF 系列（佣金 > 0、报告期 12 个月；训练 5,984）；Y = ln(AGG_COMMISSION)，X = ln(MONTHLY_AVG_NET_ASSETS)，G = IS_INDEX；13 个控制
- 关键数字（训练集，预设设定、仅 1 次）：R² = 0.493，adj R² = 0.492，ΔR² = 0.302；斜率 主动 0.75 / 指数 0.62；P10→P90 = 1.63 SD / 1.34 SD；交互 −0.136，p = 1e-8，HC3 p = 3e-9；加 ln资产×软美元研究 后交互降至 −0.083（p = 0.002）
- 诊断：残差偏度 −1.11、超额峰度 4.7；残差 ICC：基金家族 0.154、注册人 CIK 0.242、主顾问 0.177（均红旗 > 0.05）
- 失败原因：R² 0.493 < 0.50（adj 0.492），且同一家族/信托内基金高度相关（ICC 0.15–0.24），不满足严格 IID

## 组2｜加州地方政府债务发行的债券律师费：log(律师费) ~ log(本金) × 私募配售（2026-09-30）
- 数据源：https://debtwatch.treasurer.ca.gov/ （CDIAC DebtWatch 发行数据集，2021–2025 已售，每发行人保留最近一次）
- n = 1,825 次发行（训练 1,278）；Y = ln(BondCounselFee)，X = ln(PrincipalAmount)，G = PrivatePlacement；控制：年份、债务类型、发行人类型、应税、评级、再融资、浮动利率、增信、ln 期限、律所
- 关键数字（训练集，预设设定、仅 1 次）：R² = 0.630，adj R² = 0.620，ΔR² = 0.110；斜率 公募 0.30 / 私募 0.23；P10→P90 = 1.10 SD / 0.84 SD；交互 −0.074，p = 0.029，HC3 p = 0.15；加 ln本金×是否评级 后交互 p = 0.96
- 诊断：残差偏度 −4.6、超额峰度 76；Cook's D 最大 1.08；按购买方/贷款方 ICC = 0.127（红旗）
- 失败原因：交互 p > 0.01、HC3 p > 0.05，且被"是否评级"完全解释（混杂检查失败）；残差极端厚尾

## 组2｜SEC Form ADV 投顾规模：log(RAUM) ~ log(投顾雇员) × 是否管理私募基金（2026-09-30）
- 数据源：https://www.sec.gov/data-research/sec-markets-data/information-about-registered-investment-advisers-exempt-reporting-advisers （2026-09-01 注册投顾快照；以 Item 2A(1) 为注册依据的美国投顾）
- n = 13,440（训练 9,405）；Y = RAUM，X = Item 5.B(1) 投顾雇员，G = Item 7B 私募基金顾问；15 个控制（BIC 选后 14 个）。设定尝试 3 次（ADV-1 全样本峰度 29；ADV-2 采用；ADV-3 反向回归交互 p=0.20）
- 变换后最终模型（log-log）：R² 0.690，adj 0.689，ΔR² 0.172；斜率 传统 0.69 / 私募 0.97；P10→P90 = 1.18 / 1.65 SD；交互 0.279，p=8e-62，HC3 p=5e-40；替代交互（×业绩费、×个人组合管理、×理财规划、×托管、×账户数）全通过；2019 年不重叠美国样本复现 n=2,718，交互 0.189，HC3 p=7e-4
- Part 1 原始尺度（RAUM 美元 ~ 雇员人数）：R² 0.117，交互 HC3 p=0.14，P10→P90 仅 0.01 / 0.04 SD，残差峰度 3,131，Cook's D 最大 3.5
- 失败原因：未达方案一（SOC）水平——原始尺度初步模型 R²、HC3 p、效应量均不达标；总体按 RAUM≥1 亿美元的注册依据定义，对 Y 截断；反向回归（雇员 ~ RAUM）交互不显著（HC3 p=0.17）；美国以外注册投顾（n=570）复现方向相反（−0.16，HC3 p=0.08，但该样本几乎没有零售理财型顾问）

## 组2｜加州市政债发行利率：TIC(%) ~ 最终到期年限 × 联邦应税（2026-09-30）
- 数据源：https://debtwatch.treasurer.ca.gov/ （CDIAC DebtWatch，2021–2025 已售固定利率发行，每发行人最近 1 次）
- n = 2,080（训练 1,456，其中应税 207）；Y = TIC（%），X = 到最终到期年数，G = 联邦应税（vs 免税）；控制：本金、评级、增信、私募、竞争性发行、再融资、可赎回、资本增值债、债务类型、发行人类型、售出季度
- 关键数字（训练集，原始尺度预设模型、仅 1 次）：R² = 0.769，adj R² = 0.762，ΔR² = 0.034；斜率 免税 0.039 / 应税 0.026 个百分点每年；P10→P90 = 0.74 / 0.49 SD；交互 −0.013，p = 0.023，HC3 p = 0.26；加 到期×年份 后 HC3 p = 0.12
- 诊断：残差偏度 1.0、超额峰度 12.9；Box-Cox λ = 0.74；按购买方 ICC 0.49、按县 ICC 0.053（红旗）
- 失败原因：交互 p = 0.023 > 0.01 且 HC3 p = 0.26 > 0.05；替代交互下均不显著

## 组2｜汽车贷款定价：APR(%) ~ 借款人征信分 × 二手车（2026-09-30）
- 数据源：https://www.sec.gov/cgi-bin/browse-edgar?action=getcompany&type=ABS-EE （Santander Drive Auto Receivables Trust 2025-3 发行时资产池 EX-102，2024-06 至 2025-05 发放、非厂商贴息、有征信分）
- n = 47,448 笔贷款（训练 33,214）；Y = 合同 APR（%），X = 征信分，G = 二手车（vs 新车）；控制：期限、贷款额、LTV、车龄、共同借款人、收入/就业核验、车型、例外审批、发放月份、地区
- 关键数字（训练集，原始尺度预设模型、仅 1 次）：R² = 0.365，adj R² = 0.364，ΔR² = 0.049；斜率 新车 −0.0124 / 二手车 −0.0189 个百分点每分；P10→P90（521→684 分）= −0.39 SD / −0.60 SD；交互 −0.0064，p = 3e-15，HC3 p = 5e-18，按州聚类 p = 1e-11；同时加入 征信分×LTV/期限/车龄/贷款额 后交互降至 −0.0031（p = 0.003）
- 诊断：残差偏度 0.25、超额峰度 −0.08（近似正态）
- 失败原因：R² 0.365 < 0.50（同一发行人的定价还取决于未公开的经销商加价、内部评分等）；交互效应一半以上被 征信分×车龄/期限 等替代交互解释
