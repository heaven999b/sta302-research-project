# 失败记录（组1）

## LFS 时薪：工龄 × 工会（2026-09-30）
- 数据源：Statistics Canada Labour Force Survey PUMF，2026 年 8 月（https://www150.statcan.gc.ca/n1/pub/71m0001x/71m0001x2021001-eng.htm），免注册。
- 样本：25–64 岁在岗雇员、非学生，n = 37,549（训练 26,284）。Y = 时薪（CAD）；X × G = 工龄（年）× 是否工会覆盖；控制 12 个（年龄组、性别、教育、职业 NOC10、行业 NAICS21、省、公私、临时工、企业规模、周工时、移民、婚姻）。
- 关键数字：R² = 0.417（log 工资 0.494）；ΔR²(X + X×G) = 0.011；交互 = −0.069 $/年，p = 0.021（HC3 p = 0.016）；非工会斜率 0.385 $/年（P10→P90 = 0.38 SD），工会 0.316 $/年（0.30 SD）。
- 失败原因：① R² < 0.50；② 交互 p > 0.01，ΔR² < 0.02；③ 混杂检查失败：加入 工会 × 年龄组 后交互 p = 0.23，去掉双职工家庭后 p = 0.50；④ PUMF 无住户 ID，无法做到一户一行。
- 只试了 1 个主设定 + 5 个替代交互 + 3 个子样本，没有为了达标换设定。

## EIA-861 居民电价：电力公司规模 × 所有制（2026-09-30）
- 数据源：EIA Form EIA-861 2024 年终版（https://www.eia.gov/electricity/data/eia861/zip/f8612024.zip），免注册；县质心来自 Census Gazetteer 2024。
- 样本：捆绑服务、观测值、合作社/市政/IOU/政治分区，一家公司一行，n = 1,158（训练 811）。Y = 居民平均电价（¢/kWh，= 居民收入 / 居民售电量）；X × G = log10(客户数) × 所有制（4 类）；控制 9 个（州组、居民/工业售电占比、是否自有发电、是否 RTO、每条馈线客户数、服务县数、负荷率、AMI 占比）。
- 关键数字：R² = 0.584（adj 0.553），但去掉州固定效应后 R² 只有 0.18；ΔR²(X + X×G) = 0.0197；交互 partial F p = 2.7e-7，HC3 p = 0.0045；合作社斜率 −2.18 ¢/10 倍客户（P10→P90 = −0.47 SD），市政 −0.03（0.01 SD，贴 0），IOU +1.24（HC3 p = 0.13）。
- 失败原因：① R² 主要来自州固定效应，ΔR² < 0.02；② 混杂检查失败：加入 所有制 × 客户密度 后交互 HC3 p = 0.09（合作社的"规模效应"很可能是农村低密度效应）；③ 残差超额峰度 45（阿拉斯加等小公司），n 只比 1,000 多一点。第一次设定（州固定效应 + 全部辅助变量）因辅助变量缺失 n 只剩 526（< 1000）被放弃。
- 设定尝试：共 2 个主设定 + 8 个替代交互 + 3 个子样本，没有为了达标继续换 X。

## 费城住宅成交价：居住面积 × 外观状况评级（2026-09-30）
- 数据源：City of Philadelphia OPA properties（Carto SQL API https://phl.carto.com/api/v2/sql ，表 opa_properties_public），免注册；未下载业主姓名和地址。
- 样本：2025 年最近一次成交的单户住宅，售价 ≥ $25k，去掉公寓、空地，n = 12,980（训练 9,086）。Y = 售价（千美元）；X × G = 居住面积（百平方英尺）× 外观状况（5 组）；控制 11 个（地块面积、房龄、层数、卧室、卫生间、建筑类型、车库、中央空调、质量等级、邮编组、成交月）。
- 关键数字：R² = 0.272（log 价格 0.539）；ΔR²(X + X×G) = 0.022；交互 partial F p = 6e-15（HC3 p = 2e-13）；斜率：一般 16.1 k$/100sqft（0.33 SD），新建 45.4（2.0 SD），差 5.3（CI 贴 0）。
- 失败原因：① 原始尺度 R² 只有 0.27（残差偏度 7.8，峰度 80）；② log 尺度交互 p = 0.074；③ 同时加入 面积 × 邮编、面积 × 质量等级 等替代交互后，交互 p = 0.45；④ 空间自相关明显：残差 Moran's I = 0.09（log 0.13），permutation p = 0.002；按普查区 ICC = 0.05–0.10。
- 设定尝试：1 个主设定 + 7 个替代交互 + 3 个子样本。

## SEC XBRL 公司估值：log 公众流通市值 ~ ROA × 亏损（2026-09-30）
- 数据源：SEC XBRL frames API（https://data.sec.gov/api/xbrl/frames/ ，FY2024 12 月年结财报 + dei:EntityPublicFloat 2025-06-30）与 submissions API（SIC、注册地），免注册。
- 样本：非金融、非公用事业，资产与流通市值 ≥ $10M，|ROA| ≤ 100%，每 CIK 一行，n = 1,714（训练 1,200）。Y = 公众流通市值（原始 $M 与 log）；X × G = ROA（%）× 是否亏损；控制 11 个（log 资产、杠杆、现金、研发强度、资产增长、周转率、商誉占比、是否分红、行业 13 类、注册地、总部是否在美）。刻意没用 filer category 和交易所（由流通市值门槛定义，属泄漏）。
- 关键数字：原始 $ 尺度 R² = 0.035（残差峰度 350，不可用）；log 尺度 R² = 0.720，但只放 log 资产就有 0.658；ΔR²(X + X×G) = 0.0078；交互 −0.039，p = 1.7e-8（HC3 p = 2.3e-4），替代交互全部加入后 HC3 p = 0.035；盈利公司斜率 0.031/pp（P10→P90 = 0.21 SD），亏损公司 −0.008/pp（−0.22 SD）。
- 失败原因：① R² 几乎全部来自公司规模，ΔR² < 0.02；② 两组的 P10→P90 效应都 < 0.25 SD；③ 原始尺度完全不能用，Part 1 只能直接用 log(Y)。另外此方向属于组 2 领域，按协调要求不再深挖。
- 设定尝试：1 个主设定（原始 + log 两个尺度）+ 8 个替代交互 + 3 个子样本。

## CBECS 商业建筑年电费：建筑面积 × 主要用途（EIA CBECS 2018）（2026-09-30）
- 数据源：https://www.eia.gov/consumption/commercial/data/2018/index.php?view=microdata （cbecs2018_final_public.csv，免注册）；复现用 CBECS 2012 公开微观数据。
- 样本：用电、电费为报告值（非插补）、全年使用、非空置、≤ 50 万平方英尺，n = 3,121（训练 2,185）。Y = 年电费（千美元）；X × G = 面积（千平方英尺）× 用途（9 类）；控制 11 个（地区、气候区、建成年代、层数、周营业小时、24 小时营业、电采暖、制冷比例、自用/出租、政府所有、楼控系统）。
- 关键数字：原始尺度 R² = 0.542，交互 p = 7e-67（HC3 p = 2e-12），ΔR²(X + X×G) = 0.18；但残差偏度 10、峰度 206，Box–Cox λ = 0.155。Part 2 推荐模型（BIC 选出的 log–log）R² = 0.870，交互 HC3 p = 0.0025，但 ΔR²(交互) 只有 0.0017，各用途弹性 0.79–1.08，差异很小。
- 失败原因：① 原始尺度的交互几乎全是"比例/水平差异"，换到 Part 2 的 log–log 模型后实质效应很小；② 混杂检查失败：同时加入替代交互后 HC3 p = 0.076，去掉"Other"组后 p = 0.048；③ 2012 年复现虽显著，但各组弹性排序与 2018 年不一致（Food 0.71 对 0.87）。达不到"变换后仍有实质意义并通过混杂检查"的合格门槛。
- 设定尝试：原始尺度 1 个主设定 + 9 个替代交互 + 3 个子样本；Part 2 比较了 2 种变换（log–线性、log–log），BIC/AIC 后向选择，并对最终模型做了 9 个替代交互和 1 个子样本。
