# 课程要求摘要（STA302H1 Fall 2026 Final Project）

> 本文是我们自己整理的摘要，不是课程原文。课程讲义有版权，不放进仓库。以 Quercus 上的原件为准。

## Part 0：Teamwork Agreement
- 在 Quercus 上组队。
- 用课程提供的模板写团队协议，内容包括：沟通平台、会议安排、分工、未完成任务怎么处理、什么算合格参与、不参与怎么处理。
- 全员签字，存成 PDF，和 Part 1 一起提交。

## Part 1：Research Proposal
**截止**：11 月 5 日（周四）23:59。无理由延期截至 11 月 8 日（周日）23:59，使用单独的提交入口。

### 数据要求
- 必须是开源数据，并写明下载网址。
- 至少 1,000 个观测（行）。
- 1 个适合线性回归的响应变量。
- 至少 9 个预测变量，其中至少 1 个类别变量、1 个数值变量。多水平的类别变量只算 1 个。
  - 如果把数值变量转换成类别变量，要说明理由，可以引用文献或数据本身的分布特征。
- 不能用教科书数据集，也不能用 Boston Housing 或 Red Wine Quality。
- 如果数据来自 Kaggle、UCI 等数据仓库，研究问题必须新颖，不能和数据原本的用途相同。
- 必须能查到原始数据是怎么收集的、为什么收集。查不到就要换数据。

### 模型要求
- 初步模型至少包含 9 个预测变量。
- 必须包含"类别变量 × 另一变量"的交互项。
- 做完整的残差分析。**Part 1 不修正假设**，修正留到 Part 2。

### Proposal 各节与词数上限
| 章节 | 上限 | 要点 |
|---|---|---|
| Contributions | 不计词数 | 每位成员的姓名和贡献 |
| Introduction | 400 | 研究问题；为什么用线性回归而不用更简单的方法，模型的哪一部分回答研究问题；3 篇同行评审文献各说明了什么；谁会从结论中受益 |
| Data description | 300 | 数据来源、原始收集方式与目的；响应变量的统计汇总，以及它是否适合线性模型；各预测变量的汇总（一张图或一张表），并标出偏态、离群值、缺失；说明交互项的理由（文献或图表） |
| Ethics discussion | 200 | 用 Module 3 的内容和术语回答：数据是否可信（结合数据的所有权和来源）；数据的收集和我们的使用是否合乎伦理 |
| Preliminary results | 400（含图表标题） | 拟合初步模型；评估假设并指出违反；残差图按网格排列，一行 2–3 个；模型表带 SE 或 CI；讨论结果与文献相比有没有意外。**不做修正** |
| Plan | 300 | 如何增删预测变量，用什么统计方法，哪些变量必须保留；何时检查假设、多久检查一次；考虑哪些变换以及理由；时间表，可以用 Gantt 图 |
| Bibliography | 不计词数 | APA 格式 |

### 提交物（由一名组员提交全部材料）
- 团队协议 PDF
- Proposal PDF
- Rmd 代码：包括数据子集和清洗、拟合模型、汇总表、残差分析。评分者用我们提供的数据运行后，要能得到和 proposal 相同的结果
- 原始 CSV 和清洗后的 CSV：上传到 UofT OneDrive，权限设为 "anyone in UofT with the link can access"，链接写在 Quercus 的提交评论里

缺少任何一项、格式错误或链接无法访问，都会扣分；评分者无法打开的部分记 0 分。

## 课程学习目标（与评分相关）
- 用 R 对不同数据集拟合多元线性模型。
- 区分类别预测变量、交互项和连续预测变量所刻画的关系。
- 画出合适的残差图来评估模型假设。
- 从残差图的模式中判断违反了哪条假设。
- 报告残差分析的结果，并提出下一步的处理方案。
